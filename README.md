# Chatterino-Copypasta-Detector
Plugin automatically detects pasta in your Chatterino chats allowing you to join the pasta party by simply clicking the notification or set it to automatic mode when you're busy
clicking the popup - sends the pasta and restarts the timer

command list:
/cp on/off - turn Detector on selected channel.

/cp auto (on/off) - turn automatic sending detected copypastas.

/cp timeout (time) - notification time duration.

/cp threshold (time) - Amount of repeating messages to detect copypasta.

/cp window (time) - timegate in which detector checking amount of same messages.

/cp status - shows your setting and current channels it works with.

/cp list - only shows channels it currently works with.

/cp help | /cp - shows commands available 

Plugin goes into 
"Chatterino2\Plugins\copypasta"
